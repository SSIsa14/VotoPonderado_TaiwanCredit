# Todo modelo es un voto ponderado – Grupo Taiwan

Parte grupal del proyecto final de Análisis y Ciencia de Datos, Universidad del Istmo.
Sofía Sandoval, Herman Echeverría, Jorge Ferguson y Gregorio Coronel.

Datos: `data/taiwan_credit.csv` (Partes 2 a 5) y California Housing de scikit-learn (Parte 1).

## Estructura

```
data/          datos originales
src/           funciones compartidas (datos, pesos, evidencia)
notebooks/     un notebook por bloque
resultados/    hiperparametros.json (lo sobrescribe la validación cruzada)
figs/          figuras parteN_descripcion.png
slides/        presentación en PDF
```

## Cómo correrlo

    pip install -r requirements.txt
